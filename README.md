# MediCare Clinic — Book an Appointment

Live demo site: a medical clinic with working appointment bookings.

**What actually works (in your browser, no server needed):**
- Appointment form (service, doctor, date, time) with a booking reference
- Bookings list saved in localStorage, with cancel buttons
- Services, doctors and clinic stats sections

**Honest limits:** static front-end. No booking is sent to a real clinic and no
confirmation SMS/email is sent. Connect a booking system (e.g. Calendly,
a form backend) to take real appointments.
